# 实时新闻中心（个人版）

一个**完全在本地运行**的实时新闻聚合桌面程序：收集国内外权威媒体、政府 / 官方机构的一手信源，按 **P0 / P1 / P2** 分级展示，并附带微博 / 百度 / 知乎 / 国际热搜榜单。

---

## 一、这是什么（一句话）
把"各国官网 + 权威媒体"的新闻，用网页技术做成一个**只属于你、装在电脑里的桌面软件**，双击就能看，不联网对外公开。

## 二、技术原理（专业 + 通俗）

| 你要的功能 | 专业做法 | 大白话 |
|---|---|---|
| 看到的新闻卡片 / 榜单 | HTML + CSS + JavaScript 写的本地网页 | 做了一个"私人新闻网站"，只是不对外 |
| 变成 Windows 程序 | **Electron**：把网页装进自带浏览器内核的窗口，打包成 `.exe` | 一个"带浏览器的空壳"，把网页塞进去，双击即用 |
| 去各国官网抓新闻 | 主进程（独立系统进程）用 `fetch` 抓取 RSS / 官方接口 | 后台另起一个进程去搬数据，界面不卡 |
| 规避"跨域"限制 | 抓取在 Node 主进程完成，不受浏览器同源策略约束 | 浏览器本不让网页去别人家搬数据，后台进程没这限制 |
| 信源分级 | 给每个源打 `P0/P1/P2` 标签，界面彩色徽章显示 | 一眼看出这条新闻来自"一手"还是"转载" |

**为什么不是"纯前端"？** 实时新闻要跨网站抓取，浏览器的跨域安全规则会拦住网页直接拿第三方数据。Electron 自带一个最小"后台"，能合法抓取并转交界面，所以更稳定可靠——这也回答了你"纯前端能否可靠"的疑问：在此场景下，带最小后台更稳。

## 三、怎么用（已为你编译好，直接运行即可）

### 办法 A：直接双击运行（推荐，最简单，无需安装）
程序已经打包完成，你**不需要再装任何东西**：
1. 进入本项目的 `dist\NewsCenter\` 文件夹。
2. 双击 **`NewsCenter.exe`**（或同目录的 **`启动.bat`**）—— 程序窗口就会打开，新闻自动开始加载。
3. **阅读新闻**：点击任意新闻卡片，会弹出文章详情面板，直接在程序内看正文；想跳浏览器，点面板底部的「用浏览器打开原文」。

> 整个程序就是一个独立文件夹，拷贝到任何一台 Windows 电脑上都能直接双击运行，不需要安装、也不依赖网络。

### 办法 B：用浏览器先看看界面（最简，但部分源抓不到）
直接用浏览器打开项目根目录的 `index.html` 也能看界面。但浏览器有跨域限制，部分新闻源抓不到（会显示"暂未获取到"）——所以**推荐办法 A**。

### （可选）想改完源码再重新打包？
源码都在项目根目录（`main.js` / `assets/` 等）。需要重新打包时，先装 Node.js，在本文件夹打开命令行执行 `npm install` 再 `npm start` 即可进入开发模式；`build.bat` 可重新生成安装包。普通使用无需此步骤。

## 四、功能说明
- **新闻流**：封面图、标题、发布时间、发布者 / 机构、分类（时政·国际 / 财经·经济 / 科技·数码 / 社会·民生·健康）、地区（国内 / 国外）、信源等级徽章。卡片按 **月 / 日** 自动插入分割线，一目了然知道新闻归属。
- **时间分割线**：首页新闻流按月份、日期自动分组（顶部显示「2026-08 月」「2026-08-04 星期X」）。
- **程序内阅读 + 收藏**：点击卡片弹出文章详情面板，直接展示 RSS 抓到的正文；若 RSS 只给了摘要且原文链接可用，自动后台抓取完整正文替换显示。详情页更宽，滚动时顶部封面图**渐隐**、标题/发布者/时间/分类吸顶。面板内可一键**收藏**新闻。
- **图片加载与本地缓存**：封面图带加载进度动画；失败显示「图片加载失败 / 网络或源地址问题」。图片可按设置**下载到本地**（UUID 命名、永不重复），支持离线查看；可设为「仅收藏的新闻缓存」或「关闭」。
- **搜索**：首页顶部支持按 **标题关键词**、**发布者**（名称匹配）、**发布时段**（起止日期）检索，与筛选联动。
- **筛选**：按 地区 / 分类 / 信源等级 / 多选发布者 / 时段 组合过滤。
- **日历**：首页热搜榜下方有日历组件，标记有新闻的日期；点击某天即筛选当天新闻，可一键清除时段恢复全部。
- **热搜榜**：微博、百度、知乎、国际（Reddit）四个标签页；每个榜单配置备用线路，失败自动切换并显示原因。**每条热搜都可点击**，弹出详情并可一键在浏览器打开。
- **发布者与机构**：「发布者」标签浏览所有采集源机构介绍（全称、国家/地区、政治倾向、背景、LOGO）；按地区/等级/倾向筛选与搜索；**点击任意发布者卡片即跳转其官网**。
- **可视化**：「可视化」页用图表展示按领域、地区、发布者（Top10）、国家、每日趋势的分布，支持按时间范围（近7天/30天/全部）切换，样式与整体 UI 统一。
- **全球地图**：「地图」页用腾讯地图标注新闻位置（**位置仅供参考**）。发布者官方地址用蓝点、新闻事发/采访地点用橙点；hover 任一标记时其他标记降透明度以凸显；点击新闻标记可直接打开详情。地图基于标题地点识别 + 地理编码（方案B），发布者坐标兜底（方案A）。需在「设置 → 地图 API」填入你的地图 Key 后方可使用。
- **设置**：「设置」页可配置运作机制（自动刷新、启动刷新、刷新间隔）、图片缓存策略、信源启停、地图 API Key（含验证与本日调用次数）、数据目录、以及按日期或一键清理本地缓存。
- **本地缓存与去重**：新闻按天缓存到 `data/cache/news_cache_YYYY-MM-DD.json`（文件名含 news/cache/日期）；每次刷新按 **标题+链接+时间+发布者** 去重，一致则跳过。下次打开先加载本地缓存，同时后台刷新获取新内容，大幅降低刷新压力。
- **Apple 风格 UI**：大圆角卡片、玻璃拟态顶栏、柔和阴影、细腻 hover/lift 微动画、自定义纤细滚动条，整体风格统一清晰。
- **刷新**：打开自动刷一次（可在设置关闭）；默认每 15 分钟自动刷新；可随时点「立即刷新」。每次刷新在**后台进程**进行，顶部有进度条，界面不阻塞。

## 五、信源分级（P0 / P1 / P2）
- **P0 一手信源**：各国政府 / 官方机构发布、权威媒体官方首发（如白宫、国务院、联合国、WHO、欧盟委员会、新华网等）。
- **P1 可靠信源**：主流通讯社、知名媒体（BBC、卫报、NHK、纽约时报、NPR、德国之声等）。
- **P2 参考信源**：聚合平台、社媒热点、转载（热搜榜本身即属此类），仅供参考。

## 六、怎么增删信源（不用懂编程）
打开 `assets/sources.js`：
- **加新闻源**：复制里面任意一段 `{ ... }`，改 `name`（名字）、`url`（RSS 地址）、`grade`（等级）、`region`（cn/us/uk/eu/jp/intl）、`categories`（politics/finance/tech/society）。
- **加热搜源**：在 `HOT_SOURCES` 里照葫芦画瓢，写明 `url` 和 `parse`（把返回数据整理成 `{title, url, hot}` 的格式）。
- 保存后重新打开程序即可生效。

## 七、目录结构
```
main.js             Electron 主进程（后台抓取 + 窗口）
preload.js          安全桥接脚本
index.html          界面入口
assets/
  styles.css        Apple 风格深色 UI 样式
  sources.js        信源配置（可增删，见上文）
  feedparser.js     RSS/Atom 解析（无依赖）
  datalayer.js      抓取编排 + 进度回调 + 信源启停
  store.js          本地持久化层（设置/缓存/收藏/图片）
  app.js            界面交互逻辑（搜索/筛选/日历/可视化/地图/设置）
  chart.umd.min.js  可视化图表库（本地化，离线可用）
package.json        项目 / 打包配置
build.bat           一键打包成 exe
dist/NewsCenter/    已编译好的、可直接运行的程序（含 NewsCenter.exe 与 启动.bat）
```

### 数据目录（程序运行目录下的 data/）
```
dist/NewsCenter/data/
  settings.json              设置（含信源启停、刷新间隔、图片策略、地图 Key、数据目录）
  cache/news_cache_YYYY-MM-DD.json   按天的新闻缓存（文件名含 news/cache/日期）
  images/img_<uuid>.<ext>   本地化图片（UUID 命名，永不重复）
  favorites.json             收藏的新闻
  geo_usage.json             地图 API 本日调用次数
  image_manifest.json        图片 URL → 本地文件 映射
```
> 数据根目录可在「设置 → 数据目录」中修改（修改后重启生效）；留空则为程序目录下的 `data/`。

## 八、注意事项
- 个别官网 RSS 地址可能随时间变动；若某源长期抓不到，在 `sources.js` 里更新其 `url` 即可。
- 本程序仅用于**个人阅读**，请遵守各信源网站的使用条款。
- 热搜接口（尤其微博、知乎）依赖第三方聚合，偶发不可用属正常；本版已为每个热榜配置备用线路，并会显示具体错误信息，新闻流不受影响。
- 发布者页面的 LOGO 直接引用各机构官网 favicon；若机构未提供或网络受限，会显示文字占位。
- 程序内完整正文依赖 RSS 是否提供，或站点是否允许被抓取。部分站点（如 France24）对自动化访问有保护，程序会显示「无法获取完整正文」，此时点击「用浏览器打开原文」即可阅读全文。
- **地图功能需要 Key**：地图使用腾讯地图（合规要求）。请到腾讯位置服务 https://lbs.qq.com/ 申请 Key，在「设置 → 地图 API」填入；未填则地图页提示需配置。地图标记位置为参考值（发布者官方地址 + 标题地点识别），非精确定位。
- **本地缓存与图片**：缓存与图片保存在程序目录 `data/` 下；可在设置中清理。图片以 UUID 命名确保唯一，便于再次正确加载。
- 数据目录默认在 `exe` 同级 `data/`；修改「设置 → 数据目录」后需重启程序生效。
